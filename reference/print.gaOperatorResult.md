# Print method for gaOperatorResult objects

Custom print method for results returned by the GA operator. Displays
only:

- Final selected model code

- Final selected model name

## Usage

``` r
# S3 method for class 'gaOperatorResult'
print(x, ...)
```

## Arguments

- x:

  An object containing GA operator output (class gaOperatorResult).

- ...:

  Additional arguments (currently unused).

## Value

Invisibly returns the input object.
